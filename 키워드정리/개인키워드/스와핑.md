## 🧠 스와핑(Swapping)이란?

운영체제에서 **메모리가 부족할 때** 자주 사용하지 않는 **프로세스를 메모리에서 꺼내고**,
그 빈 자리에 다른 **프로세스를 대신 적재해서 실행하는 방식**입니다.

---

## 🔁 작동 흐름

1. **현재 메모리에 적재된 프로세스** 중에는 당장 실행되지 않는 것들이 있습니다.
   예: 입력 기다리는 중이거나, 오랫동안 사용되지 않은 것들

2. 이런 프로세스는 메모리에서 꺼내고 → **디스크의 일부분(보조기억장치)** 에 저장합니다.
   이때 쓰이는 디스크의 영역이 바로 **"스왑 영역(swap space)"** 입니다.

3. 이렇게 메모리에서 꺼내는 작업을 **스와프 아웃(swap-out)** 이라고 합니다.

4. 반대로, 나중에 이 프로세스를 다시 실행하려면 → **메모리로 다시 가져와야** 하겠죠?
   이 작업을 **스와프 인(swap-in)** 이라고 합니다.

---

## 💡 핵심 요약

| 용어        | 의미                                    |
| --------- | ------------------------------------- |
| **스와핑**   | 메모리가 부족할 때, 프로세스를 디스크와 메모리 간에 교체하는 작업 |
| **스왑 영역** | 디스크 중에서 임시 저장소로 사용하는 공간               |
| **스왑 아웃** | 프로세스를 메모리에서 디스크로 내보내는 것               |
| **스왑 인**  | 디스크에 있던 프로세스를 다시 메모리로 불러오는 것          |

---

## ✅ 추가 팁

* 스왑 인되면 **이전의 주소로 돌아올 수도 있지만**,
  대부분은 **다른 주소에 재적재**될 수 있음 (즉, 항상 같은 자리에 돌아오는 건 아님).

* 이는 프로세스의 **가상 메모리 관리 시스템**이 있기 때문에 가능합니다.
