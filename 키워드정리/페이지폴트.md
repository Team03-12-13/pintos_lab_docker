Page Fault는 CPU가 참조한 가상 메모리 주소가 메인 메모리에 없는 경우 발생하는 예외 상황


## 페이지 폴트 발생 과정
1. CPU가 잘못된 주소 접근 → Page Fault 예외 발생
2. 커널이 인터럽트(현재 실행 중인 작업을 잠시 멈추고, 긴급한 일을 처리한 후 다시 돌아오도록 만드는 신호) 를 받아 처리
3. 해당 주소가 올바른 주소인지 검사 (유효한 주소라면 계속 진행, 아니면 종료)
4. 필요한 페이지를 디스크(물리 디스크()) 에서 읽어옴
5. 프레임 할당 및 페이지 테이블 갱신
6. 프로세스 실행 재개
